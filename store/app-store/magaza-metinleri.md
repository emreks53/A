# App Store bilgileri

App Store Connect'te "App Information" ve sürüm sayfası için hazır metinler. Ekran
görüntüleri bu klasörde: `iphone-6.9/` (1320×2868) ve `ipad-13/` (2064×2752), altışar tane
(`tool/magaza/` aracıyla yeniden üretilir).

**Ad** (20/30): `Lügat-ı Risale-i Nur`

**Alt başlık** (29/30): `Osmanlıca kelimelerin manası`

**Tanıtım metni** (≤170):
```
Risale-i Nur okurken bilmediğiniz kelimenin ilk harflerini yazın, manası hemen gelsin. İnternet gerekmez; okurken ekran kapanmaz.
```

**Anahtar kelimeler** (≤100, virgülle, boşluksuz):
```
risale,nur,lügat,lugat,osmanlıca,sözlük,said,nursi,külliyat,kelime,mana,arapça,farsça
```

**İnceleme notu (App Review Information > Notes):**
```
Lügat-ı Risale-i Nur is an offline Ottoman Turkish dictionary for readers of the Risale-i Nur books. No login, no network access, no data collection. The app keeps the screen awake while open. On iPhone, apps cannot enable Do Not Disturb themselves, so Settings shows a one-time Shortcuts automation guide for users who want notifications silenced while reading.
```
